# 项目说明文档

## 1. 项目概览

本项目是一个功能完善的博客社交平台，采用前后端分离架构。前端基于 React 和 Vite 构建，后端基于 Spring Boot 开发。项目集成了用户管理、博客发布与互动、即时通讯（私信）、好友系统、通知系统以及 AI 助手等功能。

## 2. 技术栈

### 前端 (Frontend)
*   **核心框架**: React 18
*   **构建工具**: Vite
*   **路由管理**: React Router DOM 7
*   **HTTP 客户端**: Axios
*   **富文本编辑器**: Tiptap, React Markdown
*   **UI/样式**: CSS Modules, Highlight.js (代码高亮)
*   **其他**: Live2D Widget (看板娘), COS JS SDK (腾讯云对象存储前端直传)

### 后端 (Backend)
*   **核心框架**: Spring Boot 3.5.7
*   **语言**: Java 17
*   **数据库**: MySQL (配合 Flyway 进行版本迁移)
*   **ORM**: Spring Data JPA
*   **安全认证**: Spring Security + JWT
*   **消息队列**: Spring AMQP (RabbitMQ)
*   **AI 集成**: Spring AI
*   **对象存储**: Tencent Cloud COS
*   **工具库**: Lombok, MapStruct, JJWT

## 3. 项目结构

### 后端结构 (`backend/`)
*   `src/main/java/com/kirisamemarisa/blog/`
    *   `controller/`: API 控制器，处理 HTTP 请求。
    *   `service/`: 业务逻辑层。
    *   `repository/`: 数据访问层 (JPA Repository)。
    *   `model/`: 数据库实体类。
    *   `dto/`: 数据传输对象，用于前后端交互。
    *   `config/`: 配置类 (Security, Web, Redis, AI 等)。
    *   `common/`: 通用工具类 (ApiResponse, JwtUtil, ExceptionHandler)。
    *   `ai/`: AI 相关服务与控制器。
    *   `events/`: 事件发布与监听。

### 前端结构 (`front/`)
*   `src/`
    *   `components/`: 可复用组件 (Article, BlogEditor, Common, Home, Layout, SelfSpace, User 等)。
    *   `pages/`: 页面组件 (Home, ArticleDetail, BlogEditor, Login, Register 等)。
    *   `contexts/`: React Context (Auth, Theme, AI Assistant 等)。
    *   `hooks/`: 自定义 Hooks (useAuthState, useTheme 等)。
    *   `utils/`: 工具函数 (API 封装, 常量, 辅助函数)。
    *   `styles/`: 全局与模块化样式文件。

## 4. 数据库设计 (Database Schema)

项目使用 MySQL 数据库，主要包含以下数据表：

*   **`users` (用户表)**: 存储用户基本信息。
    *   `id`: 主键
    *   `username`: 用户名 (唯一)
    *   `password`: 密码 (加密)
    *   `gender`: 性别
    *   `is_vip`: 是否 VIP
    *   `created_at`, `updated_at`: 时间戳

*   **`user_profile` (用户资料表)**: 存储用户详细资料，与 `users` 表一对一关联。
    *   `user_id`: 主键，关联 `users.id`
    *   `nickname`: 昵称
    *   `avatar_url`: 头像 URL
    *   `background_url`: 背景图 URL
    *   `signature`: 个性签名
    *   `bio`: 个人简介
    *   `qq`, `wechat`: 社交账号
    *   `qq_qr_code`, `wechat_qr_code`: 二维码图片 URL

*   **`blog_post` (博客文章表)**: 存储博客内容。
    *   `id`: 主键
    *   `user_id`: 作者 ID
    *   `title`: 标题
    *   `content`: 内容 (Markdown/HTML)
    *   `cover_image_url`: 封面图
    *   `directory`: 目录/分类
    *   `status`: 状态 (PUBLISHED 等)
    *   `like_count`, `comment_count`, `view_count`: 统计数据
    *   `is_repost`, `original_post_id`: 转发相关

*   **`comment` (评论表)**: 存储博客评论。
    *   `id`: 主键
    *   `blog_post_id`: 关联博客
    *   `user_id`: 评论者
    *   `content`: 内容
    *   `like_count`: 点赞数

*   **`comment_reply` (评论回复表)**: 存储对评论的回复。
    *   `id`: 主键
    *   `comment_id`: 关联父评论
    *   `user_id`: 回复者
    *   `content`: 内容

*   **`private_messages` (私信表)**: 存储用户间私信。
    *   `id`: 主键
    *   `sender_id`: 发送者
    *   `receiver_id`: 接收者
    *   `text`: 文本内容
    *   `media_url`: 媒体文件 URL
    *   `type`: 类型 (TEXT, IMAGE, VIDEO)
    *   `read_by_receiver`: 是否已读

*   **`friend_requests` (好友申请表)**: 存储好友申请记录。
    *   `sender_id`, `receiver_id`: 申请双方
    *   `status`: 状态 (PENDING, ACCEPTED, REJECTED)

*   **`follows` (关注表)**: 存储用户关注关系。
    *   `follower_id`: 关注者
    *   `followee_id`: 被关注者

*   **`notifications` (通知表)**: 存储系统通知。
    *   `sender_id`, `receiver_id`: 触发者与接收者
    *   `type`: 通知类型 (点赞、评论等)
    *   `is_read`: 是否已读

*   **其他关联表**: `blog_post_like`, `blog_post_favorite`, `blog_post_share`, `blog_post_tag`, `tag`, `category` 等。

## 5. 部署与配置

### 部署方式
项目支持 Docker Compose 一键部署。
*   `docker-compose.yml`: 定义了 MySQL, Redis, RabbitMQ 等基础服务。
*   `redeploy.sh`: 自动化部署脚本，用于拉取代码、重建容器。

### 关键配置 (`application.properties`)
后端配置主要通过环境变量注入，关键配置项包括：
*   **数据库**: `spring.datasource.url`, `username`, `password`
*   **Redis**: `spring.data.redis.host`, `port`
*   **RabbitMQ**: `spring.rabbitmq.host`, `port`, `username`, `password`
*   **JWT**: `jwt.secret` (密钥)
*   **腾讯云 COS**: `cos.secretId`, `cos.secretKey`, `cos.bucketName`, `cos.region`
*   **AI (OpenAI/DeepSeek)**: `spring.ai.openai.api-key`, `spring.ai.openai.model`

## 6. 前端路由结构

前端使用 React Router 定义路由，主要路径如下：
*   `/`, `/home`: 首页 (Home)
*   `/welcome`: 欢迎页 (Welcome)
*   `/selfspace`: 个人空间 (SelfSpace)
*   `/blog-edit`: 博客编辑器 (BlogEditor)
*   `/post/:id`: 博客详情页 (ArticleDetail)
*   `/messages`, `/conversation/:otherId`: 消息中心/私信会话 (CommunicationPage)
*   `/friends`, `/friends/pending`: 好友列表/待处理申请
*   `/follows`: 关注列表 (FollowingList)
*   `/favorites`: 收藏夹 (FavoritesPage)
*   `/search`: 博客搜索 (SearchPage)
*   `/users/search`: 用户搜索 (UserSearch)
*   `/notifications`: 通知中心 (NotificationCenter)
*   `/security`: 安全中心 (SecurityCenter)

## 7. 功能模块详解

1.  **用户系统**:
    *   注册、登录 (JWT 认证)。
    *   个人资料管理 (头像、背景图、签名、社交账号绑定)。
    *   用户数据统计 (获赞数、粉丝数等)。
    *   密码修改。

2.  **博客系统**:
    *   博客的增删改查 (CRUD)。
    *   支持 Markdown 和富文本编辑。
    *   分类与标签管理。
    *   互动功能：点赞、收藏、分享、评论、回复。
    *   浏览量统计。
    *   支持上传封面图和媒体文件 (图片/视频)。

3.  **社交系统**:
    *   **关注机制**: 关注/取消关注用户，查看粉丝/关注列表。
    *   **好友系统**: 发送好友申请、接受/拒绝申请、好友列表。
    *   **即时通讯 (私信)**:
        *   支持发送文本、图片、视频。
        *   支持消息撤回、删除。
        *   支持分享博客卡片预览。
        *   基于 SSE (Server-Sent Events) 的实时消息推送。

4.  **通知系统**:
    *   基于 SSE 的实时通知推送。
    *   通知类型：点赞、评论、关注、好友申请、系统通知等。
    *   未读消息计数与标记已读。

5.  **AI 助手**:
    *   集成 AI 对话功能。
    *   支持流式响应 (Streaming)。
    *   支持带附件 (图片/文本) 的多模态对话。

6.  **搜索系统**:
    *   用户搜索 (按用户名或昵称)。
    *   博客搜索 (按关键词、分类等)。
